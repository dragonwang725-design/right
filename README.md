 # 没有统一的"对"：人工智能研究的学科重构与使用侧转向

## ——*安全关键系统中判断的情境性与决策主体形成*

**摘要**
#

当前人工智能研究面临的不是技术瓶颈，而是范式危机。工具侧研究不仅预设了存在统一"正确分布"的认识论幻觉，更通过RLHF将特定标注群体的偏好伪装成"人类反馈"、通过RAG将语义仲裁权让渡给概率模型，**悄然**完成了**决策主权**的转移，使责任链在技术黑箱中断裂。本文指出，“对”与“错”是对立统一的，不存在剥离主体与情境的绝对“**对**”；大语言模型的幻觉不是技术缺陷，而是概率生成机制与“判断必须以事实为依据”的结构性背离，在原理上不可消除，只能在架构上拦截。
本文以两条公理奠定使用侧学科的形式根基：事实必须绑定于具体系统方可进入决策空间；实然与应然的冲突必须显式化，不可消解冲突必须触发系统中断。在此基础上，本文界定使用侧研究的四大理论支柱——私域事实学、裁决动力学、责任拓扑学与安全拦截学，论证其方法论为“约束范式”而非“优化范式”。TDA架构作为使用侧可形式化的早期例证，其功能不是“消除幻觉”，而是在承认幻觉必然性的前提下建立不可绕过的事实硬约束。

**关键词**：使用侧人工智能；工具侧；决策主体；情境性；私域事实；安全关键系统；学科重构；跨学科；范式转换

## 一、引言：不是工程问题，是范式危机

过去十年，人工智能研究经历了前所未有的工具侧繁荣。从Transformer到多模态基座模型，从Scaling Law到推理时计算扩展，研究者的核心关切始终围绕一个问题：**模型能做什么？** 这一问题驱动了万亿级参数规模的跃迁，也将大模型的知识生成能力推向了逼近人类专家的水平。

然而，一个更为根本的问题始终处于研究的边缘地带：**当模型的输出被采纳为安全关键场景中的最终决定时，这个"决定"对"这个系统"而言为什么是有效的？** 这一问题涉及私域事实的锚定、判断的情境性、实然与应然的张力裁决、责任链的可追溯结构——它不是模型能力的线性延伸，而是完全不同的认识论命题。

托马斯·库恩在《科学革命的结构》中指出，科学发展的常态是"正常科学"——在既有范式内不断修补、优化、扩展。只有当旧范式开始解释不了越来越多的反常现象时，才会触发范式转换。当前AI研究正处于这一节点：工具侧研究（更大模型、更多数据、更强对齐）是"正常科学"的典范，但它解释不了一个根本的反常——**为什么模型越强大，安全关键场景的部署越危险？** 这不是技术不足，而是范式本身的盲区。

当前的行业实践将这一问题视为工具侧研究的"工程配套"：RAG用于检索增强，护栏用于事后过滤，人工审核用于人力兜底，RLHF用于对齐人类偏好。这些措施在概率层面打转，却未将"事实"作为独立的、不可取消的架构层，更未追问一个前提性问题：**是否存在一个统一的"对"的分布，等待模型去逼近？**

本文的回答是否定的。"对"与"错"是对立统一的。同一医疗方案，对"青霉素过敏的患者"是错的，对"无过敏史的患者"是对的；同一古董，对收藏家是"有价值"，对极简主义者是"累赘"。**没有脱离"我是谁"的绝对"对"。** 大模型试图在公共语料中习得"正确的分布"，本质上是试图用统计平均抹平所有情境差异，制造一个虚假的普遍正确性。这不是技术的不足，这是对"判断"本质的误解。

因此，本文的核心命题是：**当前AI研究的最大危机，不是模型不够强，而是整个学科在回答一个错误的问题。** 工具侧研究问"如何让模型输出'对'的答案"，使用侧研究问"在什么事实约束下，这个输出对'这个系统'而言是有效的判断"。这两个问题不可通约，需要独立的学科框架。

本文结构如下：第二节诊断工具侧的认识论天花板；第三节以两条公理奠定使用侧学科的形式基座，并界定其理论骨架；第四节明确工具侧与使用侧的边界；第五节以TDA作为使用侧可形式化的早期例证；第六节讨论学科建制的跨学科文化与长周期验证前提；第七节回应来自工程一线与工具侧研究者的潜在质疑；第八节为结论。

## 二、工具侧的认识论天花板

### 2.1 概率生成机制的本体论缺陷

几乎所有新学科都起源于哲学问题。牛顿之前，"为什么苹果会掉下来"是哲学；牛顿之后，它成为物理学。图灵之前，"机器能思考吗"是哲学；图灵之后，它成为计算机科学。香农之前，"什么是信息"是哲学；香农之后，它成为信息论。他们的共同特征是：将哲学问题转化为可数学表达、可工程验证的科学问题。

当前AI研究回避了一个同样根本的哲学问题：**判断与概率的关系是什么？** 大模型研究者将其降格为工程问题——"如何减少幻觉"——却未追问幻觉的结构性根源。本文将这一问题重新哲学化：概率不是事实，逻辑推演不是判断，"对"是情境性的而非分布性的。唯有先回到这一哲学起点，才能建立真正有效的使用侧学科。

大语言模型的运作机制是在公共语料中习得词语共现概率，在查询时输出概率最高的序列。它所做的不是"判断"，而是**在不知道事实的情况下，模拟判断的语言形式**。当事实与概率冲突时，模型服从概率；当事实缺失时，模型用概率填补空白。

这一机制的本体论缺陷在于：**概率不是事实，逻辑推演不是判断。** 概率描述的是"公共语料中词语如何共现"，事实描述的是"这个系统当前的状态是什么"。前者是统计的、通用的、可迁移的；后者是私域的、绑定的、随时间变化的。将概率输出直接作为判断采纳，等于用"世界通常怎样"替代"此刻实际怎样"——这正是幻觉的结构性根源。

### 2.2 知识的条件式真与事实的确定状态

工具侧研究的一个深层盲区，在于混淆了**知识的逻辑形式**与**事实的逻辑形式**。

**知识的逻辑形式是条件式（if-then）：**

$$\forall x, \text{If } P(x) \text{ then } Q(x)$$

牛顿定律、医学指南、刹车距离公式，其本质都是这种条件式真。它们陈述的是：**如果**某个参考系成立、**如果**某个患者符合前提、**如果**某个路面条件满足，**那么**某个结果将随之发生。知识不承诺"此刻 $P$ 是否成立"，它只承诺" $P$ 与 $Q$ 之间的蕴含关系"。

**事实的逻辑形式是确定命题：**

$$P(a) \land Q(a)$$

其中 $a$ 是**此刻这个具体系统**。事实不是"如果"，事实是"此刻确定如此"。它不是普遍的条件式，而是将条件式中的变量 $x$ **实例化为当下确定性状态**后的结果。

**从知识到判断，必须完成一次"条件式落地"：**

1. **识别**：当前系统 $a$ 是否满足知识的前提条件 $P$ ？
2. **绑定**：将知识中的变量 $x$ 绑定为具体对象 $a$ ；
3. **决断**：在确认 $P(a)$  成立的前提下得出 $Q(a)$ 的结论。

**大模型的结构性缺陷在于：它只拥有知识的条件式真，没有能力完成"条件式落地"。** 它的训练语料中充满了"如果过敏则禁用青霉素"的条件式知识，但它的概率生成机制无法自动识别"此刻这个患者（ $a$ ）是否属于过敏人群"。它输出的是"青霉素通常有效"这一条件式的后件，却跳过了"前提是否成立"的事实校验。

这正是"概率不是事实"的形式化表达：概率生成系统处理的是条件式在公共语料中的**统计强度**（"如果 $P$ 则 $Q$ "在训练集中出现的频率），而非条件式在具体场景中的**事实满足度**（"此刻 $P(a)$ 是否成立"）。

因此，**知识与事实的区分不是程度差异，是逻辑形式差异**：
- 知识 = 普遍的条件式真（if-then）
- 事实 = 当下的确定状态（ $a$ is $P$）
- 判断 = 在确认事实状态后，将条件式落地为确定命题

工具侧研究优化的是条件式真的强度（让"如果 $P$ 则 $Q$ "在更多语料中成立）；使用侧研究完成的是条件式的落地（确认"此刻 $a$ 是否满足 $P$ "）。**二者之间的鸿沟，就是使用侧研究的全部内容。**

### 2.3 "对"的情境性：判断的结构分析

从辩证法视角审视，"对"与"错"不是概率空间中的两个区域，而是**判断结构中相互定义的对立项**。判断的基本结构是"实然-应然-裁决"：

- **实然**："我是谁"——身份、处境、约束；
- **应然**："我要什么"——价值方向、目标；
- **裁决**：在张力中的动态选择。

**核心命题：应然本身没有根基，根基是实然给的。** 没有实然，应然就是空的——不是"没有根基"，是"没有内容"。

> 例：同一古董。
> - 实然A："我是收藏家，有仓库，有保养能力"→应然："有价值要收藏"→裁决：要
> - 实然B："我是极简主义者，住小户型，搬家频繁"→应然："占地方是累赘"→裁决：不要

**同一对象，不同实然，不同应然，不同裁决。** "对"在此不是对象的属性，而是对象与主体情境的关系属性。

大模型面对此古董，输出"具有历史价值，建议收藏"——这是公共知识的平均化表述，不是判断。它不知道"我是谁"，所以无法决断"我要不要"。它的"对"是飘着的，因为它没有实然锚点。

进一步地，这一结构不仅适用于'对'与'错'的判断，同样适用于**偏好**与**真理**——偏好无统一分布，因其无统一实然根基；真理无绝对普适，因其条件式前提的满足度随具体系统而变。RLHF试图在训练阶段定义统一偏好分布，与工具侧试图逼近统一'正确分布'，乃是同一种**认识论幻觉**的不同投影，**这是人的幻觉**。

### 2.4 幻觉的结构性必然：不是缺陷，是机制宿命

当前研究将幻觉视为技术缺陷，提出的缓解方向包括改进训练数据、增加事实核查、强化对齐、多模态grounding等。但这些方向均未能触及结构性根源：

| 缓解方向 | 盲区 |
|---------|------|
| 改进训练数据 | 数据再多，也是公共的，不是私域的 |
| 增加事实核查 | 核查是事后，不是前置约束 |
| 强化对齐 | 对齐的是偏好，不是事实 |
| 多模态grounding | grounding的是感知，不是"必须响应"的约束 |

**本文明确指出：幻觉不是技术缺陷，是概率生成机制与"判断必须以事实为依据"这一常识的结构性背离。** 任何试图通过更大模型、更好数据、更强对齐来"消灭"幻觉的努力，都是在用技术复杂性掩盖认识论简单性。幻觉在原理上不可消灭，只能在架构上被拦截。

这意味着：模型优化无法替代使用侧架构设计。安全关键系统的决策主体问题不能作为基础模型研究的附属工程问题，必须独立成科。


 ### 2.5 主权转移：工具侧的技术语法分析

 上述认识论诊断尚未触及一个更深层的结构问题：工具侧主流方案不仅**未能**完成事实绑定，而且其**技术语法本身**在悄然完成主权转移——将事实定义权、确认权与责任承担权从具体人类主体转移至不可追溯的技术黑箱。

 **定义（主权转移）**。当技术架构将责任链三要素（FDR/FCR/LAR）中的任一环节从显式的人类主体转移至匿名的算法组件，且该转移被技术中立性话语所遮蔽时，即构成主权转移。

 **案例一：RLHF的偏好主权转移**。标注者群体行使了事实上的价值定义权（FDR），但其身份匿名、偏好不可追溯；奖励模型将分散的偏好压缩为标量信号，完成了确认权的算法化（FCR被模型垄断）；最终部署者使用该模型做决策，但责任由"模型性能"这一统计概念稀释。用户面对的是"已对齐"的输出，却无从追问：**这是谁的偏好？谁授权它代表我？**

 **案例二：RAG的解释主权转移**。检索层提供候选事实，但LLM保留最终语义仲裁权——它"选择"相信哪条检索结果、如何将其融入生成，这一过程对部署者不可审计。事实确认权（FCR）从人类检索员转移至模型的概率分布，责任链在"检索-生成"的接口处断裂。

 **案例三：黑箱模型的彻底主权转移**。端到端神经网络中，FDR、FCR、LAR均无法定位。模型作为一个整体"做出决策"，但内部没有任何组件可被识别为"定义者"、"确认者"或"承担者"。责任链在架构层面彻底消散。

 **结论**：工具侧研究不仅存在认识论盲区，而且其技术语法在结构上**阻止了责任链的闭合**。这构成了对使用侧领地的结构性侵占：它用"技术优化"替代了"主权分配"，用"概率输出"替代了"判断合法化"。因此，使用侧学科的独立不是"分工协作"的温和倡议，而是**对主权转移的结构性矫正**。

## 三、使用侧人工智能：作为跨学科综合学科的定义

### 3.0 形式基座：两条不可让渡的公理

上述分析表明，工具侧范式在认识论上无法完成条件式落地，在政治经济学上无法阻止主权转移。这要求我们建立独立的使用侧学科，其首要任务不是优化模型，而是建立不可让渡的形式基座。

使用侧人工智能作为独立学科，其形式根基建立在以下两条公理之上。它们不是推导的定理，而是本学科的**不可约前提**；其形式化完备性证明与扩展定理见另文。

**公理 1（事实绑定公理）**

> 任何进入系统决策空间 $\mathcal{D}$ 的事实断言，必须呈现为绑定于具体系统的私域事实元组 $\langle \text{SystemID}, \text{Timestamp}, \text{Value} \rangle$。未绑定于具体系统的统计模式（如语言模型的共现概率 $P(w|\text{context})$）仅可被定义为**外部知识线索**，不得独立作为裁决依据。

**公理 2（冲突裁决公理）**

> 实然约束与应然输出之间的任何冲突 $C$ 必须被编码为可审计结构；不可消解冲突 $C \in \mathcal{C}_{\text{irr}}$ 必须触发系统中断 $\bot$，不得由概率生成机制自行语义消解。裁决机制 $\Theta$ 在事实硬约束下执行，其输出必须满足完整责任链的可追溯性条件。

**TDA作为公理承载实例**：上述两条公理在本作者前文提出的TDA架构中获得工程实现——空模型范式对应公理1（私域事实的绑定与校验），结构化辩论层、非认知熔断器与裁决AI对应公理2（冲突的显式化、不可消解冲突的中断、可追溯裁决）。TDA不是唯一实现路径，但证明这两条公理具备可编码、可验证的学科载体。

这两条公理共同表达了本文的核心判断：没有统一的‘对’——事实绑定排除了普遍正确性的幻觉，冲突裁决排除了概率平滑的替代方案。

### 3.1 学科定位

使用侧人工智能不是计算机科学的子领域，也不是工具侧研究的"应用延伸"。它是**横跨哲学、法学、安全工程、认知科学、计算机科学的综合学科**，其研究对象是**安全关键系统中决策主体的形成机制**。

"决策主体"在此不是本体论意义上的"意识主体"，而是功能意义上的**判断合法化结构**：一个系统，若其输出被作为"最终决定"采纳，则在该场景下构成决策主体。关键问题不是"它有多聪明"，而是"它的判断根基是否扎实、责任链路是否完整"。

### 3.2 核心问题域：四大理论支柱

使用侧学科的理论骨架由四大支柱构成：

| 支柱 | 来源学科 | 核心问题 |
|:---|:---|:---|
| **私域事实学** | 现象学、信息论、知识工程 | "事实"如何在具体系统中被采集、绑定、演化、版本控制？如何区分"公共知识"与"必须响应的私域事实"？ |
| **裁决动力学** | 法学、决策理论、控制论 | 实然约束与应然输出冲突时，决断如何形成？如何理解"有依据的随机"？动态阈值如何自我维持？ |
| **责任拓扑学** | 法哲学、伦理学、政治学 | 人机权责的不可混淆边界如何被形式化地**标记**，而非被技术单方面**分配**。它回答"如果事实定义权归X，则责任如何随绑定关系自动归X"；但它**不回答"事实定义权为什么归X"**——后者是政治决断，必须在技术部署前由社会过程确定。使用侧技术架构的任务是暴露并承载这一分配结构，而非替代社会做出分配。 |
| **安全拦截学** | 功能安全（ISO 26262等）、失效模式分析 | 在承认系统不完美前提下，如何构建失效安全（fail-safe）机制？如何设计"实然的最高否决权"？ |

这四大支柱的共同特征是：**它们都不研究"模型如何生成更好的输出"，而是研究"模型的输出在什么结构下可以合法地成为决策"。**

**关于事实定义权的技术边界**：使用侧研究必须严守一条红线——技术负责"怎么绑定"（binding protocol）与"冲突时怎么停"（halting mechanism），但不负责"绑什么"（what counts as fact）与"谁说了算"（sovereignty assignment）。空模型中的事实库由谁填充、动态阈值τ的调整权归谁、熔断器误触发后的损失由谁承担，这些问题没有技术答案，是**政治问题**。TDA架构的价值恰恰在于：它将这些问题**显式化、结构化**，迫使部署者必须在系统上线前回答它们，而不是让概率生成系统默默替使用者做出隐含的价值选择。

### 3.3 方法论特征：约束范式 vs 优化范式

工具侧研究的方法论是**优化范式**：损失函数最小化、性能指标最大化、基准测试刷榜。其隐含假设是"更多算力+更多数据=更好结果"。

使用侧研究的方法论是**约束范式**：事实不可违反、责任不可真空、失效必须可控、冲突必须显式化。其隐含假设是"系统必然不完美，因此必须建立不可绕过的约束层"。

| 维度 | 工具侧：优化范式 | 使用侧：约束范式 |
|:---|:---|:---|
| 核心操作 | 训练、微调、对齐、扩展 | 架构设计、事实绑定、冲突裁决、熔断拦截 |
| 评价标准 | 困惑度、准确率、人类偏好 | 事实冲突拦截率、裁决可追溯性、熔断成功率、责任链路完整性 |
| 失败观 | 失败是暂时的，可通过更多资源克服 | 失败是结构性的，必须通过约束机制管理 |
| 时间观 | 追求即时性能 | 追求长期可审计性与责任收敛 |

### 3.4 与工具侧的关系：互补而非替代

使用侧学科的独立，不是对工具侧的否定，而是对学科边界的澄清：

- **工具侧**：制造更强大的**知识引擎**。回答"世界可能是怎样的"。不绑定具体场景，不承诺决策合法性。
- **使用侧**：构建合法的**决策主体**。回答"基于当前事实应当如何决断"。不追求模型能力，追求判断根基。

二者通过**接口**连接：工具侧提供"可能性空间"，使用侧提供"约束结构"与"合法化程序"。工具侧研究者可以卸下不该承担的责任——"我们优化知识引擎，不承诺决策主体"；使用侧研究者获得独立的学术身份——"我们研究判断如何在具体系统中合法形成"。

## 四、与现有方向的边界辨析

使用侧学科必须与现有相近方向明确区分，以证明其不可被替代：

**与RAG**：RAG检索的是公共知识，目的是为模型提供额外上下文以减少幻觉。但它检索的事实是**可争论的、供参考的**，不具备"必须响应"的硬约束性质，也没有裁决与责任结构。

**与可信计算/内生安全**：可信计算保障的是**计算过程可信**——芯片到应用的全栈可靠、架构级容错。它确保系统不崩溃，但不解决"输出内容违背场景事实"的问题。过程正确不等于内容正确。

**与人在回路/人机协同**：传统人机协同将决策权归属视为模糊分工，但当前实践中"人在回路"往往沦为责任转嫁——当概率生成系统的输出不可分解、不可追溯时，回路中的人实际上无法做出有意义的决策。

**与AI安全/对齐**：RLHF、Constitutional AI等对齐技术优化的是**人类偏好**——模型"应该说什么"。这属于应然层优化。但应然本身没有根基，根基是实然给的。对齐技术不处理"我是谁"的实然事实底层约束。

**结论**：现有方向均只是使用侧研究的局部子集或邻近领域，无法覆盖"决策主体形成"的完整命题。

## 五、例证：TDA作为使用侧研究的一种实现路径

### 5.1 定位声明

TDA（Three-layer Dialectical Architecture，三层辩证架构，又称元受动极架构）**不是使用侧研究的唯一答案，甚至不是"最佳实践"**。它只是**证明该学科可形式化、可编码、可实验验证的一个早期范例**。其核心贡献不在于技术细节，而在于它示范了如何将哲学层面的"实然-应然"张力转化为工程层面的"事实约束-冲突裁决-责任追溯"结构。

### 5.2 核心机制简述

TDA的核心组件包括：

- **空模型**：一个软件程序（非AI模型），承载绑定于具体系统的私域事实。它本身不生成内容，只做空校验、空拦截、空增强——像安检门一样，"空"着但通过规则过滤一切。
- **结构化辩论层**：让LLM的应然输出与空模型的实然约束形成显式冲突图，使矛盾可审计。
- **裁决AI**：在张力中做出存在论决断，依托动态阈值τ自我维持，同一冲突在不同语境下可能不同裁决，但均可追溯。
- **非认知结构性熔断器**：当冲突不可消解时，直接中断输出，不经过LLM的语义消解。这是"实然作为最高指令"的结构化实现。

### 5.3 关键澄清：TDA不消灭幻觉

**必须首先澄清一个常见误解：TDA架构的目的不是"消灭幻觉"。**

幻觉是大模型概率生成机制的结构性必然，任何声称可以"根治"幻觉的技术承诺，都是在重复工具侧的认识论盲区。TDA的功能是**拦截**——在概率生成系统的输出与私域事实冲突时，建立不可绕过的硬约束；在冲突不可消解时，启动熔断。它不是让模型"更正确"，而是让系统"更安全地接受模型的不正确"。

TDA已完成核心机制的仿真验证（动态阈值在分类任务中将漏报率与误报率同步压低至约7%，突破固定阈值安全-可用性互斥困境），并提供静态事实约束（nmp.py）与动态事实采集（crash_probe.py）的参考实现。这些工作证明：使用侧研究不是"工程经验"，而是具有独立理论骨架与验证方法论的学科方向。

## 六、从哲学问题到科学问题：学科建制的方法论自觉

### 6.1 范式转换与问题重述

使用侧学科的建立，在库恩意义上是一次典型的范式转换。当前工具侧研究将"基准测试分数"作为进步的唯一标尺，这是"正常科学"的标准操作。但"正常科学"的危机在于：当反常现象积累到旧范式的修补无法容纳时，必须允许新框架的竞争。当前AI安全的诸多困境——护栏规则失效、对齐导致的新偏见、责任真空——正是旧范式的"反常"。

范式转换的第一步不是提出新答案，而是提出新问题。牛顿没有回答"为什么苹果会掉下来"的哲学追问，而是提出了"是否存在统一规律"的新问题，继而建立数学、预测轨道、验证假设。图灵没有沉溺于"思考是什么"的语义辨析，而是提出了"可计算性"与"模仿游戏"的操作化定义，将哲学问题引入计算机科学。香农没有讨论"语言的意义"，而是定义了信息熵，使信息论成为一门严格的数学学科。

使用侧人工智能同样始于哲学——"对"的情境性、实然对应然的锚定、决策主体的形成条件——但其目标不是哲学讨论，而是建立可形式化、可编码、可审计的科学框架。TDA架构正是这一转化的早期尝试：它将"判断必须以事实为依据"的哲学命题，转化为空模型的约束校验、辩论层的冲突图、裁决AI的动态阈值、熔断器的存在论中断——每一个组件都可编码、可测试、可追溯。

**真正的问题不是"有没有哲学"，而是"有没有把哲学问题变成科学问题"。** 使用侧研究的任务，正是完成这一转化。

### 6.2 跨学科文化：原创的源泉

使用侧AI需要哲学家（判断结构、主体性理论）、法学家（责任理论、合规框架）、安全工程师（失效模式、功能安全标准）、计算机科学家（架构实现）共同工作。没有跨学科文化，使用侧研究将沦为"给大模型加护栏"的工程杂活，无法触及决策主体形成的理论根基。

历史上，几乎所有重大原创都来自不同领域的碰撞。控制论源于数学、神经科学与工程学的交汇；认知科学源于心理学、语言学、计算机科学与哲学的融合；DeepMind的许多突破同样来自神经科学与强化学习的交叉。使用侧学科天然具有这种交叉属性：它的核心概念（如"私域事实""责任拓扑"）无法在单一学科内完全定义，必须借助多重视角才能逼近其完整内涵。

### 6.3 长周期验证与失败的认识论价值

使用侧研究面临一个根本性的时间张力：其验证周期天然漫长。一个私域事实约束系统的有效性，需要在真实安全关键场景中经历多次失效、迭代、审计，才能收敛到可信赖的责任链路。这与"正常科学"中常见的短周期迭代形成对照。

从科学史看，范式转换从来不是短周期事件。哥白尼的日心说、达尔文的进化论、爱因斯坦的相对论，从提出到被广泛接受，都经历了数十年。这不是因为早期支持者不努力，而是因为新范式需要建立全新的验证体系——旧的实验标准无法衡量新的理论价值。

使用侧研究同样需要建立**长周期验证文化**。这意味着：

**第一，重新理解"失败"的认识论地位。** 在波普尔的意义上，"知道此路不通"与"知道此路可通"具有同等的科学价值。一个被详细记录、分析、归档的约束失效案例——例如，某次熔断器因事实覆盖盲区而误触发——其贡献可能高于一个成功的基准测试分数，因为它为整个学科排除了错误路径。使用侧研究的评价体系应当容纳这种"证伪贡献"，而非仅奖励"证实成功"。

**第二，建立"失败档案"作为学科公共品。** 安全关键系统的真实失效案例（在脱敏与伦理审查前提下）应成为使用侧研究的核心数据。这些档案不是"负面结果"，而是约束理论的边界标记。正如航空史上的空难调查推动了飞行安全理论的进步，AI安全中的熔断与拦截案例也将推动使用侧理论的收敛。

**第三，跨学科协作的风险共担机制。** 使用侧研究需要跨学科团队，但跨学科合作天然面临评价权分散的困境：哲学贡献在计算机顶会上难以被识别，工程实现在哲学期刊上缺乏共鸣。学科建制必须为这种协作提供"翻译层"——既懂技术逻辑又懂规范语言的复合型人才，以及能够同时理解形式化模型与责任理论的评审标准。没有这种共担机制，最优秀的研究者将因职业安全考量而回避高风险的跨学科前沿。

**简言之**：使用侧学科的健康发展，依赖于学术生态对"长周期"与"失败"的重新理解。它不是对研究者的宽容请求，而是对创新本质的诚实——**原创性突破从来不是从正确走向更正确，而是在约束条件下管理必然的失败，从中筛选出不被淘汰的范式。**

## 七、潜在质疑与回应——致务实者

任何学科倡议都必须经受来自工程一线与工具侧研究者的拷问。以下回应三个最尖锐的质疑。

### 7.1 质疑一：物理规律难道不是"统一的对"？

**质疑**：您否定"统一的对"，但牛顿定律、欧姆定律、刹车距离公式难道不是普适的、统一的"对"？如果这种"对"存在，工具侧追求逼近它就有意义。

**回应**：物理规律确实具有统一性，但**"统一"不等于"普适适用"**。牛顿定律在宏观低速参考系下是有效的，但在接近光速或强引力场的事实条件下不适用——这不是牛顿定律"错了"，而是**它的适用边界受限于参考系**。同样，一个医学指南可能在90%的患者身上有效，但对"这个青霉素过敏的患者"不适用。

本文第二节已从逻辑形式层面阐明：知识是"如果……那么……"（if-then）的条件式真，事实是"此刻这个系统的实然状态"。物理定律的"统一性"是条件式的统一，不是落地的统一。**知识服务于事实，而非事实服从知识。** 工具侧研究优化的是知识的条件式真；使用侧研究填补的是"条件式真"与"此刻实然"之间的鸿沟。二者之间不存在替代关系。

### 7.2 质疑二：为什么不归到功能安全或工业自动化？

**质疑**：约束、熔断、责任链、失效安全——这不就是ISO 26262、IEC 61508的功能安全范畴吗？功能安全工程师已经干了二十年，何必新造一个学科？

**回应**：功能安全与使用侧研究解决的是不同层面的问题。功能安全的核心假设是：**系统的意图是正确的，只是执行过程可能出错**（硬件随机失效、软件bug、电磁干扰）。它回答的问题是："如果系统坏了，如何确保安全状态？"

使用侧面对的是一个**功能安全从未处理过的新问题**：**系统没有坏，计算过程完全正确，但输出内容违背了场景事实。** 一个医疗AI，计算过程零bug，硬件无故障，但它建议给青霉素过敏患者使用青霉素——这不是功能安全问题，这是**判断根基缺失**问题。一个自动驾驶系统，所有传感器正常，算力充足，但它基于公共驾驶数据的概率分布，误判了"此刻这条结冰弯道的摩擦系数"——这不是执行故障，这是**私域事实未绑定**问题。

更深层的区分在于：功能安全的HARA方法假设危害场景是**可枚举的**；但大模型的幻觉空间是**开放性、不可枚举的**——你无法用传统的FMEA穷尽一个概率生成系统的所有错误输出。功能安全是**工程规范**，使用侧是**跨学科理论**（涉及判断结构、法哲学、责任拓扑）。功能安全可以**吸纳**使用侧成果（如在ISO 26262框架内嵌入空模型约束层），但无法**孕育**使用侧的理论根基。

使用侧绝不僭越到"谁有权定义'该不该'"——后者是功能安全与使用侧都必须让渡给社会治理的问题。

### 7.3 质疑三：产业界等不起长周期验证

**质疑**：您说要容忍失败、长周期验证，但车企明年就要量产，医院这个月就要上线。没有量产车敢装一个"理论正确但没跑过百万公里"的系统。这个学科在产业界一天都活不下去。

**回应**：这不是"慢验证 vs 快部署"的选择，而是"盲目部署 vs 安全部署"的选择。

**首先，使用侧提供的是可分级部署的渐进路径，而非"等完美再落地"的拖延。** TDA架构的三层验证已呈现清晰的工程节奏：第一层裁决机制已完成仿真验证，可立即集成；第二层静态事实约束（nmp.py）已开源，可立即在医疗、金融等场景中部署私域事实拦截；第三层动态事实闭环（crash_probe.py）核心探针机制可先行试点，完整大规模验证随产业数据积累逐步收敛。

**其次，当前产业界的"快速部署"本质上是"没有验证就部署"的冒险。** 大模型在通用基准上测试后直接投入安全关键场景——通用基准验证的是"公共知识概率"，不是"私域事实约束"；验证的是"模型能否生成流畅文本"，不是"系统能否在事实冲突时合法决断"。

**最后，使用侧恰恰是让"百万公里验证"变得有意义的前提。** 没有使用侧框架，"跑百万公里"收集的只是更多统计样本——它验证的是"模型在这百万公里中碰巧没出错"，而不是"系统建立了不可绕过的事实约束"。使用侧提供的**可追溯裁决链**，使得长周期验证不再是"碰运气跑里程"，而是**结构化地收敛责任边界**：每一公里都在检验事实覆盖度、冲突拦截率、熔断准确率——这些才是安全关键系统真正需要验证的东西。

## 八、结论

本文基于安全关键系统决策主体形成机制的分析，论证了"使用侧人工智能"作为独立跨学科综合学科的合法性：

**第一**，大模型幻觉的必然性在于其概率生成机制与"判断必须以事实为依据"的结构性背离。这一缺陷不是技术不足，而是认识论盲区——它预设了存在一个统一的"对"的分布，忽视了"对"的情境性与对立统一性。本文进一步指出，知识是条件式真（if-then），事实是当下确定状态，判断必须完成从条件式到确定命题的"落地"。工具侧研究优化条件式真，使用侧研究完成条件式落地。

**第二**，本文以两条公理奠定使用侧学科的形式根基：事实必须绑定于具体系统方可进入决策空间；冲突必须显式化且不可消解冲突必须触发系统中断。在此基座上，使用侧研究具有独立研究对象（决策主体形成）、独立方法论（约束范式）、独立评价标准（责任导向）。其四大支柱——私域事实学、裁决动力学、责任拓扑学、安全拦截学——横跨哲学、法学、安全工程与计算机科学。

**第三**，TDA架构作为早期例证，证明使用侧研究可形式化、可验证，但其功能不是"消灭幻觉"（这在结构上是做不到的），而是在承认幻觉必然性的前提下建立不可绕过的事实硬约束与失效安全机制。

**第四**，使用侧学科的健康发展依赖于学术生态的变革：容忍范式挑战、鼓励跨学科融合、建立对长周期验证与失败的合理接纳机制。

人工智能的未来，不在于模型多强大，而在于**我们是否承认：没有统一的"对"，只有绑定于具体事实的"有效判断"**。高可靠AI的安全前提不是"模型完美"，而是在承认模型结构性不完美的条件下，建立"判断归机、目的归人"的主体形成机制。
